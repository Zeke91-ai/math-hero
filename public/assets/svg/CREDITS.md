# Kredit Aset

Aset gambar di folder ini tidak dibuat oleh tim game ini. Pemakaian mengikuti lisensi masing-masing sumber.

## SVG Repo (https://www.svgrepo.com)

Vectors and icons by SVG Repo (https://www.svgrepo.com)

Lisensi SVG Repo: pemakaian untuk game ini diizinkan dan atribusi tidak wajib, namun dianjurkan.
Aset tidak dijual dan tidak didistribusikan ulang sebagai koleksi.

| File | Koleksi SVG Repo |
|---|---|
| chick, bee | animal-pixel-art-vectors |
| apple, banana, cherry, grape, strawberry, pineapple, watermelon | fruit-pixel-icons |
| candy, lollipop | pixel-art-colored-icons |

Koleksi yang tidak dipakai: tiny-people-avatar-vectors, pixeled-nft-vectors,
animal-outlined-sepia-icons, nature-flat-icons, cute-animal-vectors, food-line-filled-vectors.
